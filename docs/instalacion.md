# Instalación de Street Rod SE para PSP

1. Descargá el ZIP de la [primera versión pública](https://github.com/pc-master-sw/street-rod-se-psp/releases/tag/v0.1.0).
2. Extraé la carpeta `STREETROD-SE` y colocala en `PSP/GAME` de la Memory Stick.
3. Copiá `SRSE.EXE` y los archivos LIB1, LIB2 y HOT_DATA de tu edición DOS a `STREETROD-SE/Game`.
4. Abrí Street Rod SE desde **Juego** en el menú de la PSP.

El directorio del juego debe quedar como `PSP/GAME/STREETROD-SE`. Debe contener
`EBOOT.PBP` y el subdirectorio `Game` con los datos DOS. El ZIP incluye
el programa, las instrucciones y sus fuentes. Los datos DOS se agregan desde tu copia.

Al iniciar, el port crea la carpeta `Save`. Para importar partidas, copiá
allí tus archivos `HOTROD1.SAV a HOTROD15.SAV` de Street Rod SE. Antes de actualizar una instalación,
hacé una copia de esa carpeta.
