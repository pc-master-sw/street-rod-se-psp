# Cómo jugar Street Rod SE en PSP

En la licencia, usá Cuadrado para ingresar tu nombre y Start para
confirmar. Desde los avisos, elegí un auto y entrá al garaje. La opción
`Hit the street` lleva al Drive-In, donde podés desafiar a otro conductor.

Para guardar, abrí `Save, Restart, or Quit` desde el garaje y elegí
`Save Game`. Para continuar tras reiniciar, seleccioná `Old Game` con Cruz
en la licencia, elegí la partida y confirmá con Start.

## Controles

| PSP | Acción |
|---|---|
| Cruceta o stick | Mover el cursor. Al conducir, arriba acelera, abajo frena y los lados giran. |
| Cruz | Clic o selección. Al conducir, también envía la barra espaciadora. |
| Círculo | Escape o cancelar. |
| Cuadrado | Abrir el teclado en pantalla. Sirve para escribir el nombre y para los atajos de una tecla de los menús. |
| Start | Enter o enviar lo escrito en el teclado. |
| Select | Borrar el último carácter. |
| L / R | Bajar / subir marcha. En un auto automático, R selecciona Drive. |
| Triángulo | Enviar la tecla M, atajo de música del motor. |
| Start + Select | Salir. Guardá primero desde el menú del garaje. |
